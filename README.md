# Machine Learning Assignment 1

Polynomial regression models for two datasets using regularization and cross-validation.

## Approach

- Polynomial feature expansion with `PolynomialFeatures`
- Feature scaling using `StandardScaler`
- Hyperparameter tuning using `GridSearchCV` with K-Fold cross-validation
- **Problem 1:** Lasso Regression
- **Problem 2:** Ridge Regression
- Final models are used to generate test predictions.

## Tools

- Python
- NumPy
- Pandas
- Scikit-learn
- Google Colab
